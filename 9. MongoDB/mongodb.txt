MongoDB:
--------
*) No SQL database
*) Uses JSON-like documents with optional schemas. It's called BSON
*) RDBMS Vs MongoDB
+----------+------------+
|  RDBMS   |  MongoDB   |
+----------+------------+
| Tables   | Collections|
| Rows     | Documents  |
| Columns  | Fields     |
+----------+------------+
Collections similar to Folder
Documents similar to JSON Files

*)Inside a collection, documents will be available in BSON format.
+-------------------------+------------------------------------------+----------------------------------------------------+
| JS Object               |     Used inside JS code                  | {name: "Hana", age: 25}                            |
| JSON                    |     Data format for APIs & communication | {"name": "Hana", "age": 25}                        | 
| BSON(Binary JSON)       |     Binary format used by MongoDB        | {_id: ObjectId("abc123"), name: "Hana", age: 25}   |
+-------------------------+------------------------------------------+----------------------------------------------------+
!!!We write JS objects. MongoDB stores BSON!!!

*) check RDBMS_vs_MondoDB.png
*) The _id field:
In MongoDB, each Document stored in a Collection requires a unique _id field that acts as a primary key. If
an inserted document omits the _id filed, the MongoDB driver automatically generates an ObjectId for the _id
field. Eg: 507f191e810c19729de860ea
*) Atlas:
Atlas is a fully managed cloud database service provided by MongoDB. It allows users to deploy, manage and
scale MongoDB databases in cloud, without the need for complex infrastructure setup & maintenance. It's paid
*) 2 Editions:
Community edition (CE) - free & open source
Enterprise edition (EE) - paid. Support team will be there in case of any issues
*) MongoDB Shell (mongosh) & MongoDB Compass:
In order to connect with Postgres, we use pgAdmin or PSQL commandline tool to interact & use queries.
lly, MongoDB Shell (mongosh) is a commandline tool. We can use this MongoDB shell to test queries & operations
directly with our database. MongoDB Compass is similar to pgAdmin. Both mongosh & MongoDB Compass are free.
Usually Mongosh is used in production. Nobody uses Compass (GUI tools) there. So understand the commands better.
*) Mongoose:
A js OOP library that creates connection b/w MongoDB & Node.js javascript runtime environment.
We can install this using npm. For Postgres, we used 'pg' library.
If you wanna connect Java or other apps to MongoDB, separate drivers are available

*)SQL SELECT statements  Vs MongoDB find() statements:

+--------------------------------------------------------------+-----------------------------------------------------------------+
|            SQL SELECT statements                             |                 MongoDB find() statements                       |
+--------------------------------------------------------------+-----------------------------------------------------------------+
| SELECT * FROM people                                         | db.people.find()                                                |
| SELECT id, userid, status FROM people                        | db.people.find({}, {userid: 1, status: 1})                      |
| SELECT userid, status FROM people                            | db.people.find({}, {userid: 1, status: 1, _id: 0})              |
| SELECT * FROM people WHERE status = "A"                      | db.people.find({status: "A"})                                   |
| SELECT userid, status FROM people WHERE status = "A"         | db.people.find({status: "A"}, {userid: 1, status: 1, _id: 0})   |
| SELECT * FROM people WHERE status != "A"                     | db.people.find({status: {$ne: "A"}})                            |
| SELECT * FROM people WHERE status = "A" AND age = 50         | db.people.find({status: "A", age: 50})                          |
| SELECT * FROM people WHERE status = "A" OR age = 50          | db.people.find({$or: [{status: "A"}, {age: 50}]})               |
| SELECT * FROM people WHERE age > 25                          | db.people.find({age: {$gt: 25}})                                |
| SELECT * FROM people WHERE age > 25 AND age <= 50            | db.people.find({age: {$gt: 25, $lte: 50}})                      |
| SELECT * FROM people WHERE user_id like "%bc%"               | db.people.find({user_id: /bc/})                                 |
| SELECT * FROM people WHERE user_id like "%bc%"               | db.people.find({user_id: {$regex: /bc/}})                       | -> alternative regular expression method
| SELECT * FROM people WHERE user_id like "bc%"                | db.people.find({user_id: /^bc/})                                |
| SELECT * FROM people WHERE user_id like "bc%"                | db.people.find({user_id: {$regex: /^bc/}})                      | -> alternative regular expression method
| SELECT * FROM people WHERE status = "A" ORDER BY user_id ASC | db.people.find({status: "A"}).sort({user_id: 1})                |
| SELECT * FROM people WHERE status = "A" ORDER BY user_id DESC| db.people.find({status: "A"}).sort({user_id: -1})               |
| SELECT COUNT(*) FROM people                                  | db.people.count()                                               |
| SELECT COUNT(user_id) FROM people                            | db.people.count({user_id: {$exists: true}})                     |
| SELECT COUNT(*) FROM people WHERE age > 30                   | db.people.count({age: {$gt: 30}})                               |
| SELECT COUNT(*) FROM people WHERE age > 30                   | db.people.find({age: {$gt: 30}}).count()                        | -> alternative method
| UPDTAE people SET status="C" WHERE age>25                    | db.people.updateMany({age: {$gt: 25}}, {$set: {status: "C"}})   |
| UPDTAE people SET age=age+3 WHERE status="A"                 | db.people.updateMany({status: "A"}, {$inc: {age: 3}})           |
| DELETE from people WHERE status="D"                          | db.people.deleteMany({status: "D"})                             |
| DELETE from people                                           | db.people.deleteMany({})                                        |
+--------------------------------------------------------------+-----------------------------------------------------------------+
